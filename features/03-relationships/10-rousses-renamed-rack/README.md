# Relationships · 10 · Rousses renamed rack

On 10 September Claire Roux reprints the cave book. The rack list that was meules is now wheels. PL-19 still names its rack. The shelf label has no previous name.

**What it teaches**

- `wheels` stores the original name `meules`.
- The inverse `rack` stores its own name. `label`, which omits `originalName`, stores an empty string.
