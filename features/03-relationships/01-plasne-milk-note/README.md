# Relationships · 01 · Plasne milk note

On 2 September Hélène Pellier writes 86 litres at Ferme Pellier. The fruitière line is blank until she names Lucien Morel's desk, Fruitière du Plateau de Plasne.

**What it teaches**

- An optional to-one can be absent.
- Naming the fruitière puts this note on its roll. The link is to-one, its destination is `Fruitiere`, and its inverse is `notes`.
