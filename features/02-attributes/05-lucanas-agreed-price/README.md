# Attributes · 05 · Lucanas agreed price

The morning of the chaccu, Nélida Apaza locks 480 soles for the comunidad, to be paid by Casa Rojas in La Paz.

**What it teaches**

- `@Attribute(.preserveValueOnDeletion)` marks `agreedSoles`.
- The mark is the lesson. This screen does not delete the row.
