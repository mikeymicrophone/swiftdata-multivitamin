# Transient · 06 · Hide case

On 7 April Cemil Arslan cuts an oxhide case. He sets aside three spare thongs and says the stitch should stay proud of the seam.

**What it teaches**

- Both the stitch aside and the spare-thong count are omitted from the schema.
- A new context resets both. The grade is oxhide.
