# Transient · 04 · Stem nick

On 5 April Halime Öztürk fits a cherry stem. The nick starts as still in the cloth. She sets it to tight on the tenon.

**What it teaches**

- A non-optional transient needs a default. The macro rejects the property without one.
- A new context reads still in the cloth. The wood is cherry.
